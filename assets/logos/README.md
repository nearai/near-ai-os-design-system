# Logos

The Near AI master brand, copied unchanged from the Near AI logo kit. Three lockups, each in four colorings.

| Lockup | Files | Use |
|---|---|---|
| Primary: the "near AI" wordmark | `near-ai-primary-color.svg`, `-black.svg`, `-white-color.svg`, `-white.svg` | The default. Site headers, sign-in, about screens, marketing. |
| Secondary: the "N" monogram with "AI" | `near-ai-secondary-color.svg`, `-black.svg`, `-white-color.svg`, `-white.svg` | Where the wordmark does not fit: narrow headers, compact toolbars, favicons at large sizes. |
| Tertiary: the tile | `near-ai-tile-color.svg`, `near-ai-tile-white-color.svg` | App-icon contexts, avatars, social cards. Never as a button. |
| Clear space | `near-ai-primary-clear-space.svg`, `near-ai-secondary-clear-space.svg` | The minimum margin around each lockup, drawn by the kit. |

Inks (an `<img>` cannot inherit color, so each file carries its own):
- Color: "near" in `brand-ink` black, "AI" in `brand-blue` #0091fd. Light grounds only.
- White & color: "near" in white, "AI" in `brand-blue`. Dark grounds only.
- Black and White: single-ink versions for one-color printing, embossing and grounds where blue would clash.
- Tile: color is a `brand-tile` #0b8ff6 tile with the "N" in `brand-paper` #f3f3f2; white & color is a white tile with the "N" in `brand-tile`.

Rules: never recolor, redraw, outline, stretch or add effects; never place the color lockup on a dark ground or the white lockup on a light one; never set "Near AI" in a typeface to imitate the wordmark; keep the clear space from the clear-space files on every side. The kit sets no minimum size; ask the brand owner before using the wordmark below 72px wide.
