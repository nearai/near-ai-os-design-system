# Trace

Product marks for Trace (the trace-commons app, shipping as "Near.ai"; the commons is "Trace Commons"). Product marks never replace the NEAR AI master brand; they sit beside it or inside the product.

| Mark | Files | Use |
|---|---|---|
| Trace mark, live trace | `trace-mark-live.svg` | A trace across a 3 by 3 lattice: visited nodes in the live gradient (`trace-live-start` #5b14ff to `trace-live-mid` #b412c4 to `trace-live-end` #ff0a6c, with a glow on the current step) and unvisited nodes in `trace-purple` #6d14f3. Dark grounds. Transcribed point for point from `GlassTraceMark.swift` (200-unit box). |
| Trace mark, ink | `trace-mark-ink-white.svg`, `trace-mark-ink-black.svg` | One ink, every node at full strength (the edge-rail icon). White on dark grounds, black on light. |
| The Turn | `the-turn-dark.svg`, `the-turn-light.svg` (framed), `the-turn-glyph-dark.svg`, `the-turn-glyph-light.svg` (frameless), `the-turn-template-dark.svg`, `the-turn-template-light.svg` (one ink) | The packaging and app-icon mark from `assets/mark/`: an open bracket in mint #00d4aa and a close bracket in ink. Its mint is a legacy color outside the token set; the brand owner has yet to decide whether The Turn converges on the Trace mark. |

Rules: copy these files, never redraw them; the gradient mark is for 30px and up (below that use the ink mark); never put the gradient mark on a light ground.
